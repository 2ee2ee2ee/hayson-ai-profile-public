# Hayson · Public AI Profile

我是一名大学生，学习电气工程技术（EET）。这份档案可作为 AI 协作的背景资料。

## 学习与项目

- **电气工程技术**：EET114 住宅电气设计、EET117 电路理论。学习主题包括串并联、KCL、KVL、分压分流、叠加与 Thévenin / Norton 等效。住宅作业使用 CEC 2024，需要核查规则号和设备规格。
- **纸间学习活页夹**：手机端学习资料管理构想，涵盖拍照扫描、PDF、批注和标签。
- **电脑装机**：先核对配件兼容性、稳定性与保修，再比较价格和性能。
- **AI 音乐**：用 Google Flow Music 尝试纯器乐抒情曲，例如 72 BPM 的《无声惦念》（Silent Yearning），以钢琴、弦乐和大提琴为主。

## 如何与我协作

- 可用普通话、粤语或英语。中文交流优先用中文，必要时保留并解释英文术语。
